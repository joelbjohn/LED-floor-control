# LED floor control and games that use it

We did this project during our college cultural fest. These codes control an array of 4*10 tiles with us having the freedom to choose what color we want for each tile. This was achived by gluing the led strips to custom made wooden frames which can house the mirror to reflect the led light and a glass slab which goes over the frame, protecting the mirror and the internals. A group of 4 tiles, arranged in a bigger square is connected to an esp 32 to control the color of the tile. Therefor a total of 10 esps where used to control the entire board. Instructions from the laptop was sent to the esp using a router which connected both esps and the laptop.
